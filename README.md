# SnakeManiaGame
This is a classic Snake game built from scratch using HTML, CSS, and JavaScript. The game features a dynamic board, a scoring system, and a high-score tracker that uses local storage to save your best score.

Features:

1. Classic Gameplay: Navigate the snake to eat food and grow longer.

2. Collision Detection: The game ends when the snake hits a wall or itself.

3. Scoring: Tracks your current score as you play.

4. High Score: Your highest score is saved in your browser's local storage.

5. Responsive Design: The game board is built to be playable on different screen sizes.

Technologies Used:

1. HTML: For the game structure.

2. CSS: For styling the game board and elements.

3. JavaScript: For the core game logic, including movement, scoring, and collision detection.

How to Play:

1. Clone this repository to your local machine :
   git clone https://github.com/harsh-verma-2004
/SnakeMania.git

2. Open the index.html file in your web browser.

3. Use the arrow keys (Up, Down, Left, Right) to control the snake's direction.

4. Try to eat the food and beat your high score!
